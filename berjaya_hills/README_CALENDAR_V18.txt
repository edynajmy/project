v18 CALENDAR ARCHIVE & UX
Based on the user's v14 ALL-PLACES-IN-VENUES project.

Implemented:
- Month / Week / Day / List / Timeline view switch.
- List and Timeline cover the selected archive year.
- Timeline progressively reveals more records as the user scrolls.
- Upcoming vs Past quick filter.
- Archive year selector.
- Past event cards use muted/greyscale treatment.
- Upcoming events show Remind Me (browser local storage) and View Event.
- Past events link to an enhanced recap page.
- Recap page supports event_gallery + gallery_images.
- Optional event_testimonials table and display.
- Share button supports native share where available, with WhatsApp/Facebook/TikTok fallbacks.
- Existing v14 venue/location data is preserved.
- Optional SQL: database/add_event_archive_features.sql
