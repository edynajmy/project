GALLERY V98 — IMAGE FIT / NO FORCED ZOOM

- Public gallery album covers now use object-fit: contain so portrait, landscape, and square uploads remain fully visible without forced cropping.
- Removed the hover scale enlargement; only a subtle brightness response remains.
- Original uploaded image files and their resolution are not modified by this CSS change.
- Lightbox already uses object-fit: contain and remains unchanged.
- Note: contain may show neutral empty space around images with different aspect ratios. It avoids cropping and does not upscale image detail.
