VENUE IMAGE FIX
================
The venue listing now:
1. Uses venue_images from the database when available.
2. Falls back to real Berjaya Hills / The Chateau images when the database image_path is empty.
3. Uses the same fallback on public/venues/view.php.
4. Includes responsive card/image CSS.

If you later add local images to assets/images/venues/ and seed their paths into venue_images,
the database images will take priority over the fallback URLs.

Homepage signature venue cards now use the same venue_image_url() fallback system, so the four cards on index.php also show real venue/resort images instead of the green/gold placeholder.
